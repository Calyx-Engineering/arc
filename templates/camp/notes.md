## The test

> **Does acting on this change what Camp is obliged to do?**

| Answer | Where it goes |
|---|---|
| **Yes** | A proposed amendment to the agreement. Camp drafts the diff; the user approves it |
| **No — it makes an existing obligation better-informed** | Here. Camp writes it freely |

| Belongs here | Does not |
|---|---|
| Where this repo keeps things Arc's defaults do not predict | A preference about how Camp behaves — that is an amendment |
| Which checks have been noisy here | A fact about the product — that graduates to the wiki |
| Recurring shapes in how work runs in this repo | Anything the `arc-log` or a `dev-log` already records |

**Notes are committed and diffable**, so a wrong note is visible and correctable rather than
silently shaping behaviour.
