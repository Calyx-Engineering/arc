description: Resume the arc from the handoff — read it, then execute its ordered actions

Invoke the `handoff` skill and take the reading path.

**This command holds no rule of its own.** The skill carries the reading order, the staleness
checks that run before a handoff is acted on, and what to do when there is no handoff or no
ordered actions. A rule that lives here instead is one an opening that reaches the skill by
wording — *"read HANDOFF.md first"*, *"pick up where we left off"* — never sees.
