Invoke the `handoff` skill and take the writing path.

**This command holds no rule of its own.** The skill carries what a handoff holds, the fixed
order — save the transcript, then write the file, then give the prompt — and what belongs in
the committed record instead of here. A rule that lives here instead is one an opening that
reaches the skill by wording — *"write the handoff"*, *"give me the prompt for the next
chat"* — never sees.
